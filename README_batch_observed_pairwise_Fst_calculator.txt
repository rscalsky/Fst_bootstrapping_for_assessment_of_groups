This is a README for batch_observed_pairwise_Fst_calculator.sh

This script takes three inputs 

-i input directory containing ID lists for your sites of interest

-o output directory for all pairwise Fst results 

-v input VCF that contains all the samples of interest

This script will run all unique pairwise combinations of populations founded within the -i directory and deposit their Fst estimates in the 
-o directory.
